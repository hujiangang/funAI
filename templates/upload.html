A LITTLE HELP

发布前的小贴士

  1. 让它可以直接打开

    支持完整 HTML；多文件作品请压缩包含 index.html 的目录。

  2. 带上需要的素材

    JS、CSS、图片与音频一起打包，资源路径使用相对路径。

  3. 先构建，再上传

    React / Vite 等项目请上传 dist 或 build 产物。当前不支持 RAR、7z 或服务端程序。

  4. 亲手体验一下

    试运行会提示脚本和资源加载错误。交互是否符合预期，需要你亲自确认。
