# funAI
测试保存一些AI生成的游戏



**主框架：FastAPI**

- 基于 **Python** 编写的高性能 Web 异步框架
- 主打：异步请求、自动接口文档、高性能、类型提示友好

## 用到的配套组件

1. **uvicorn**：ASGI 异步服务器，用来运行 FastAPI 项目
2. **Jinja2Templates**：FastAPI 内置的**Jinja2 模板引擎**，用于渲染 HTML 网页
3. **StaticFiles**：托管静态资源（图片、JS、CSS、上传文件）
4. **lifespan 生命周期**：FastAPI 新版启动 / 关闭事件写法
5. **路由拆分**：`routers` 模块化拆分接口，规范项目结构

## 项目用途

这是一个**Python FastAPI 前后端一体网站项目**

- 有网页模板渲染
- 静态文件托管
- 文件上传目录浏览
- 拆分了游戏、排行榜、后台、AI 导航、关于页等业务路由
- 启动自动执行文件夹同步业务逻辑

## 同类对比

- 和 Flask：比 Flask 更快、原生异步、接口文档更强
- 和 Django：轻量极简，无臃肿组件，适合接口 + 轻网站开发
